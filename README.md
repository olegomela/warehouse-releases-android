# warehouse-releases-android
Simple Warehouse WMS App for Android - .apk releases

Stable basic WMS functionality (accounting).

Local standalone application.

Local database based on .csv files; preserved when uninstalling/reinstalling the application.
Sample database for reference.

Scanning the barcode/QR code into the Product name using device’s camera.

Interface languages: 
  - 🇬🇧 English
  - 🇫🇷 French
  - 🇩🇪 German
  - 🇪🇸 Spanish
  - 🇺🇦 Ukrainian

Download:

https://github.com/olegomela/warehouse-releases-android/releases/download/v1.4.4/warehouse-10404.apk

Requirements
  - Android 8 or later
  - Built-in camera (permission may be required)
